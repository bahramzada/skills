# Research coverage and entity identity

Adapt the coverage map to the question: subtopics, relevant populations/regions, entity classes, versions, time periods, constraints and evidence types. This is not a fixed inventory quota.

Track which areas were investigated, which were excluded by the user and which remain under-documented. Do not silently omit poorly documented segments or let convenient sources define the entire research population. Include material counterevidence and alternative explanations.

Maintain canonical entity IDs and aliases. Confirm identity using evidence; distinguish similarly named entities and changed versions. Preserve meaningful one-to-many or many-to-many relations instead of flattening them into duplicate counts.

Before comparison, align units, definitions, time periods, denominators and scope. A missing field is not a negative value. A formal classification is separate from observed behavior, availability or performance. Use field-specific evidence rather than one citation for every attribute.

A profile or comparison row should include only relevant fields: identity, source-backed attributes, conditions, dates, relations and unknowns. Define the shared field template from the user's needs. Add provenance to derived values and label estimates.

Reconcile counts using distinct canonical IDs. Distinguish a comprehensive official inventory, a sampled dataset and an editorial selection. State the basis and limits of completeness, even when a requested count is reached.
